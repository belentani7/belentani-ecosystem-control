## Propuesta de arquitectura de enlaces

```text
GitHub (prueba técnica)
  -> Portfolio profesional canónico (casos de estudio)
      -> Productos/demos estables
      -> Contacto profesional
  -> belentani.es (universo creativo)
      -> Música / experiencias / AI Lab
      -> Enlace de retorno al portfolio profesional
```

La coherencia se logra utilizando una biografía idéntica o compatible, un conjunto reducido de proyectos destacados, enlaces que funcionen y llamadas a la acción diferenciadas para colaboración técnica, obra creativa y contacto.
